# LabFlow P0 / G3 视觉事实来源规格

> 版本：G3-Visual-1  
> 日期：2026-07-29  
> 状态：制作中  
> 视觉方向：实验记录台 / Field Ledger

## 1. 目标与边界

本规格把已批准的 `G1-Countersign-5` 与 `G2-Review-3.1` 转化为可编辑、可运行、可截图验证的静态网页 UI。交付只使用代表性固定数据，不接入 Supabase、API、认证、持久化或真实业务逻辑。

最终视觉事实来源由以下内容共同构成：

1. 本规格中的视觉与组件规则；
2. `design/labflow-g3/src/` 下的可编辑 React/CSS 静态原型；
3. 页面/状态覆盖矩阵与截图证据；
4. `design-qa.md` 中的源稿对照结论。

选定的方向图只作为视觉参考，不作为最终可编辑设计文件。

## 2. 视觉方向

### 2.1 核心表达

LabFlow 应像“可信的数字实验记录簿”，而不是通用蓝白后台或科幻仪器屏：

- 象牙白连续工作表面承载长时间规划和知识阅读；
- 深墨绿形成稳定应用框架与高识别度品牌锚点；
- 氧化橙只用于已到点、阻断和需要立即处理的警示；
- 鼠尾草绿用于完成、已同步和可恢复的正向状态；
- 编辑式标题、编号、细分隔线与批次标签形成实验记录心智；
- 纸张纹理降到几乎不可察觉，不干扰数字界面的清晰度。

生产界面不显示农历信息或 `P0` 版本标签。

## 3. 布局与响应式

- 桌面 `≥1024px`：240px 左导航 + 弹性主内容；需要时使用 300px 右上下文栏。
- 紧凑 `768–1023px`：导航收窄为图标/短标签，右栏折叠到主内容后。
- 手机 `320–767px`：单列、顶部应用栏、底部五项导航与固定计时状态条。
- `390×844` 移动优先顺序固定为：当前步骤 → 到点/活动计时器 → 下一动作 → 当日日程；冲突与次日任务进入可展开次级区域。
- `320px` 不允许页面级横向滚动或主要操作遮挡。
- `200%` 缩放按窄屏重排，内容和操作仍可达。

## 4. 组件规范

- `AppShell`：桌面左导航、移动顶部栏与底部导航；公开页使用独立 Auth Shell。
- `StatusBanner`：说明发生事项、数据安全状态、可执行动作与替代路径。
- `StatusTag`：图标/形状 + 文本，不允许只使用颜色。
- `ExperimentHeader`：任务名、阶段、日期时段、方案版本、同步状态与下一步。
- `StepRail`：编号、状态文本与进度；移动端聚焦当前步骤。
- `TimerRow`：到点、运行、暂停、离线推算四种强辨识状态；同时显示相对时间、绝对目标时间、任务与步骤。
- `ScheduleBand`：早/中/晚分区和精确时间，冲突同时指出对象与重叠时段。
- `RecordList`：统一支持首批加载、加载更多、末页、局部失败与重试。
- `FormSection`：可见标签、字段说明、错误关联、保存状态与禁用原因。
- `ConflictPanel`：本机动作、服务器状态、未覆盖说明，以及“采用最新状态/重新应用我的动作”。
- `DangerZone`：删除、永久删除和账户删除使用独立区，不与普通设置混排。

## 5. 页面与状态

原型必须覆盖 G1 的 23 个页面 ID：`A01 A02 A03 O01 D01 S01 S02 W01 W02 W03 W04 K01 K02 K03 T01 N01 H01 H02 M01 P01 X01 R01 C01`。

全局状态切换至少提供：正常、加载、空、错误、禁用、离线、冲突、通知不可用、账户待删除和高密度列表。页面专属状态按 G1 §12.2 映射。

G2 用户可见增量必须出现：

- 历史中的“完成—撤销—再次完成”多份不可变快照；
- 本机 outbox 未清空时阻止完成；
- 完成确认提醒无法预知其他离线设备尚未上报的操作；
- `PARENT_COMPLETED` 进入既定冲突反馈，不新增页面；
- 知识库默认展示最新仍生效的完成归档。

## 6. 固定数据

固定用户为林晓，时区 `Asia/Shanghai`，日期锚点为 2026-07-29，晚间汇总时间 21:00。数据覆盖 G1 §14 的早中晚任务、长标题、未关联方案、八步实验、三计时器、离线 7:59/8:01、待同步 23:59/超过 24 小时、三批列表、通知降级、删除恢复和账户撤销期。

## 7. 可访问性

- 目标为 WCAG 2.2 AA；
- 普通文字对比度至少 4.5:1，大文字与必要图形至少 3:1；
- 全流程键盘可达，焦点顺序与阅读顺序一致；
- 焦点环至少 3px，并与相邻颜色有足够对比；
- 触控目标至少 44×44 CSS px；
- 状态使用文本、图标/形状和颜色三重表达；
- live region 只播报关键变化，计时器不每秒打断读屏；
- 纯文本保留换行，Markdown/HTML/脚本样式字符不解析不执行。

## 8. G3 验收定义

- 23 个页面 ID 均有可访问入口；
- 固定状态可通过原型内状态控制器切换；
- 1440×900、390×844、320px 与 200% 缩放有截图证据；
- 核心导航、状态控制、折叠区、分页/加载更多与主要静态表单交互可操作；
- 构建、语义检查、键盘检查和视觉对照无阻断问题；
- `design-qa.md` 的最终结果为 `passed`；
- 不包含真实数据接入或业务持久化。

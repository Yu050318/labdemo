# LabFlow P0 / G3 测试验收计划

> 版本：QA-P0-G3-3  
> 日期：2026-07-29  
> 状态：Sites M0 与 G3 Next.js 固定数据静态页面独立验收通过；待产品部最终门禁确认  
> 依据：G1-Countersign-5、G2-Review-3.1、QA-P0-G2-4  
> 边界：本文件只定义 G3 验收方法；没有实际产物和当前轮证据时不得判定通过

## 1. G3 完成定义

G3 需要分别形成两个互不替代的结论：

1. **Sites M0 测试结论**：验证平台最小兼容性，不代表 23 个静态页面视觉通过。
2. **G3 静态页面验收结论**：验证视觉、响应式、固定状态、键盘、焦点、语义、对比度和基本读屏，不代表真实业务功能或生产发布通过。

进入条件：

- 交付准确版本、commit 或可追溯产物。
- 提供可访问预览入口及启动方法。
- 固定数据和状态可稳定切换，不依赖真实生产数据。
- 不提供、打印或写入任何 secret 值。

退出条件：

- 23/23 页面均有可核验证据或明确阻断。
- 1440×900、390×844、320px、200% 缩放均完成检查。
- 核心流程键盘可达，焦点、语义、对比度和基础读屏不存在阻断。
- 所有 S0/S1 缺陷关闭；S2 仅在产品部书面接受风险后允许遗留。
- Sites M0 每项有独立运行证据；未测项不得记为通过。

## 2. 统一视觉与状态验收清单

每个页面至少检查：

- 页面标题、主操作、返回/导航和当前状态清晰。
- 正常、加载、空、错误、禁用状态与规格一致；适用页面额外覆盖离线、待同步、冲突和通知不可用。
- 非正常状态说明“发生了什么、数据是否安全、下一步、替代路径”。
- 错误不清空仍可用内容，不泄露凭据、实验正文或其他账户数据。
- 长标题、长备注、长步骤、长错误可换行，主要操作持续可见。
- 状态不只依赖颜色；图标按钮有可理解名称。
- 加载结束前不误显示空状态；局部加载失败不覆盖已加载数据。
- 固定数据使用 G1 §14 的代表性数据，不使用仅有理想短文本的演示数据。

## 4. 响应式与缩放

### 4.1 1440×900

- 左侧导航、主内容及可选右侧上下文不重叠。
- 双栏阅读顺序与 DOM/键盘顺序一致。
- 页面主标题和主要操作无需横向滚动即可定位。
- 日程周视图、执行步骤与当前步骤、知识库列表/详情可读。

### 4.2 390×844

- 使用单列和底部导航；主要操作不被安全区或底栏遮挡。
- 日程默认单日列表，不压缩周网格。
- 任务编辑为全屏流程；列表/详情分层进入。
- 当前步骤、已到点计时和阻断状态优先展示。
- 虚拟键盘打开后当前字段、错误和提交按钮仍可见。

### 4.3 320px

- 无页面级横向滚动。
- 长标题、标签、状态、错误和按钮文本不截断关键信息。
- 表格转卡片/定义列表，不压缩为不可读列。
- 固定底部操作不遮挡最后一项内容。

### 4.4 200% 缩放

- 核心闭环内容和操作无丢失、遮挡或双向滚动陷阱。
- 导航可访问，焦点不进入不可见区域。
- 对话框/底部面板可滚动并保持关闭、确认操作可见。
- 文本重排后标签、输入、说明和错误关联仍清晰。

## 5. 键盘、焦点、语义、对比度和基本读屏

### 5.1 键盘与焦点

- 仅键盘完成登录 → 首次设置 → 新建任务 → 关联方案 → 准备 → 步骤 → 完成确认。
- Tab 顺序符合视觉和阅读顺序，不进入隐藏/禁用元素。
- 所有交互元素有可见焦点。
- 对话框打开后焦点进入，关闭后回到触发元素。
- 错误提交后聚焦首个错误；动态追加后焦点保持或移到新增内容起点。
- 跳过、完成、撤销完成、计时调整和永久删除确认可用键盘操作。

### 5.2 语义与基本读屏

- 每页一个明确主标题；主导航、主内容、辅助区域有适当 landmark。
- 表单标签、必填、说明和错误通过语义关联。
- 当前导航、当前步骤、展开/选中状态使用正确属性。
- 进度提供文本或数值；状态变化使用适度 live region。
- 计时器不每秒播报，只在请求、关键节点和到点时播报。
- 图标按钮、链接和下载项名称可理解，不依赖视觉上下文。

### 5.3 对比度与非颜色表达

- 普通文字 ≥ 4.5:1；大文字 ≥ 3:1。
- 焦点、控件边界和重要图形满足必要的非文本对比度。
- 错误、逾期、等待中、待同步、冲突、成功不只靠颜色。
- 禁用状态仍可读，并提供禁用原因。
- 对比度使用采样工具测量，不凭肉眼判定。

## 6. 固定数据状态覆盖

必须至少能稳定进入：

- 正常、加载、空、整页错误、局部错误、禁用。
- 离线、最后同步时间、待同步、24小时超期、恢复成功/失败。
- `STALE_ENTITY_REVISION`、`PARENT_COMPLETED` 冲突及两种解决方向。
- Push 未询问、拒绝、不支持、iOS未主屏、订阅失效、投递失败、设备离线。
- 完成、撤销、再次完成的多个不可变 completion；知识库最新有效、历史全时间线。
- 高密度列表首批、加载更多、末批、追加失败、重试、条件变化、去重。
- 纯文本换行、Markdown/HTML/脚本样式字符不解析。
- 导出软删除/永久删除边界及删除恢复边界。

## 8. 缺陷分级和最小复现

- **S0 致命**：未登录泄露个人数据、secret 进入客户端、跨用户数据、不可恢复数据破坏。
- **S1 严重**：核心页面/闭环不可访问，主要操作键盘不可达，320px/200% 遮挡阻断，M0 核心能力失败。
- **S2 一般**：非核心状态、局部布局或辅助体验异常，存在低风险绕行。
- **S3 轻微**：不影响理解、操作、数据或安全的视觉细节。

每个阻断至少记录：

1. 被测版本、浏览器、视口、缩放和页面 ID。
2. 前置固定数据/状态。
3. 最短稳定复现步骤。
4. 期望结果和实际结果。
5. 截图、DOM/语义快照、控制台或构建日志证据。
6. 严重度、影响页面和是否阻断 G3/M0。

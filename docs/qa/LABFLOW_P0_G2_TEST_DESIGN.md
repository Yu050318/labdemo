## 1. 目的与覆盖结论

本文件定义 LabFlow P0 的测试范围、方法、用例目录、测试数据、发布阻断标准和生产验收要求。本轮只完成测试设计，不执行尚不存在的产品测试。

覆盖结论：

- AC-P0-01 至 AC-P0-12 均已建立测试映射，无验收标准遗漏。
- 已覆盖功能、权限、RLS、时间、时区、跨午夜、多计时器、离线、跨设备、Push 降级、导出、删除恢复、性能容量、兼容性、响应式和可访问性。
- 权限隔离、历史不可变、计时事实、离线幂等、冲突不静默覆盖、提醒降级和导出隔离列为发布重点。
- 当前没有可测试版本，因此没有执行结果，也不能给出产品质量通过结论。三份开发规格已完成 G2-Review-3.1 差异复核，G2-QA-01～04 已关闭；后续产品质量结论仍须基于实际实现和测试证据。

## 2. 测试范围

### 2.1 P0 范围内

- 邮箱密码注册、邮箱验证、登录、退出、找回密码和基础偏好。
- 个人空间与跨账户数据隔离。
- 按日期及早、中、晚创建、编辑、改期、取消和查看实验任务。
- 手工创建、编辑、搜索、关联、停用实验方案及执行版本保护。
- 器材、试剂、材料和前置准备清单。
- 实验步骤完成、取消完成、跳过、备注和进度。
- 多计时器及开始、暂停、继续、延长、缩短、结束和到期处理。
- Web Push、站内提醒、错过提醒补显及能力边界提示。
- 用户主动完成、执行记录、历史归档及方案快照。
- 晚间汇总、时区、跨午夜和去重。
- 冻结范围内的短时离线读取、勾选、待同步、幂等重放和冲突处理。
- JSON/CSV 导出、软删除、历史保护和错误信息安全。
- 账户删除、7 天撤销、30 天最近删除恢复及永久删除确认。
- 试点容量、代表性单账户数据量、页面/写操作 P95 和可操作性。
- Sites 优先部署的生产兼容性与 Vercel 回退条件。
- 正式支持浏览器、桌面/移动响应式及可访问性。

### 2.2 明确排除

P0 不设计或执行以下功能测试：

- 文件上传、文档处理、PDF、OCR。
- AI 方案提取、联网检索、多来源比较、RAG。
- Supabase Queue、pgvector、Python Worker。
- Docker、云端 Worker、桌面安装程序。
- 材料库存管理。
- 仪器、房间或场地预约。
- Zotero 集成。
- 团队成员、角色、共享或协作空间。
- 危险实验的闹钟级安全保证。

如版本中出现上述入口或能力，只检查其不会影响 P0、安全边界和发布包体；不将其作为 P0 验收内容。任何范围变化必须由产品部登记并重新评审。

## 3. 总体测试计划

### 3.1 测试目标

1. 验证完整闭环可在正式支持的桌面端和移动端完成。
2. 验证个人数据在 UI、API、数据库 RLS 和导出层均不可跨账户访问。
3. 验证方案执行快照、步骤记录、计时事实和历史归档不会被后续操作破坏。
4. 验证时间、时区、跨午夜、夏令时、多计时器和汇总去重正确。
5. 验证 Push 不可用或失败时站内提醒始终可恢复查看。
6. 验证短时离线操作只同步一次，冲突不会静默覆盖。
7. 验证 Sites 生产环境满足 Next.js、SSR/API、PWA、Service Worker、Push、环境变量和 Supabase 连接要求。
8. 验证账户删除/撤销、软删除恢复和永久删除边界符合冻结规则。
9. 验证 1,000 个账户、100 个并发活跃用户及代表性单账户数据量下的性能门槛。

### 3.2 测试层级与方法

| 层级 | 重点 | 建议证据 |
|---|---|---|
| 数据库/RLS | 默认拒绝、跨用户负向访问、服务端写入边界、不可变记录 | 策略测试结果、请求与响应、数据库断言 |
| API/服务 | 鉴权、输入校验、状态迁移、幂等、并发、导出范围 | Contract 测试、状态前后对比、错误码 |
| 单元/组件 | 时间计算、进度、计时状态、汇总日期、冲突和离线队列 | 自动化测试报告 |
| UI/E2E | 核心闭环、异常恢复、响应式、键盘流程 | Playwright 结果、截图、录屏 |
| 浏览器/设备 | 正式支持矩阵、PWA、Push 和移动端限制 | 环境记录、真机/浏览器证据 |
| 性能/容量 | 页面和核心写 P95、100 并发、代表性单账户数据量 | 压测报告、分位值、错误率、移动端操作记录 |
| 生产验收 | Sites 配置、生产域名、认证回调、核心冒烟、无数据泄露 | 部署版本、检查清单、监控截图 |

### 3.3 环境

| 环境 | 用途 | 数据要求 |
|---|---|---|
| 本地/CI | 单元、组件、Contract、迁移和 RLS 自动化 | 可重复生成并销毁的合成数据 |
| 独立测试 Supabase | API、RLS、Cron、Push、离线和并发 | 与开发环境隔离，不使用生产数据 |
| Staging | 全量 E2E、浏览器、响应式、可访问性和发布候选回归 | 固定版本、固定配置、代表性账户 |
| Sites 生产 | 发布前/后生产冒烟和部署兼容性 | 指定测试账户，最小且可清理 |

### 3.4 进入条件

- 产品基线版本固定，变更记录可查。
- 设计部提供经确认的信息架构、页面状态、交互和响应式事实来源。
- 开发部提供 Tech Spec、API Contract、数据模型、RLS、时间/提醒、离线/冲突和部署说明。
- 提供可唯一识别的候选版本、部署地址、测试账户和测试数据初始化方式。
- 开发自测、自动化检查和已知问题清单可查。
- 测试环境与生产环境隔离，不能使用或暴露真实凭据和真实实验隐私数据。

### 3.5 退出条件

- AC-P0-01 至 AC-P0-12 全部执行且通过。
- 核心闭环、RLS 负向、时间专项、离线重放、通知降级、删除恢复、导出隔离、性能容量和 Sites 生产冒烟通过。
- 正式支持浏览器与必测桌面/手机视口通过。
- 核心流程达到 WCAG 2.2 AA。
- 正常网络下普通已登录页面与核心写操作 P95 均不超过 1 秒；提醒领取和站内补显达到冻结时间窗口。
- 无未关闭的 S0、S1 缺陷；S2 遗留均有产品部书面风险接受、负责人和版本归属。
- 所有失败、阻塞、未测项和环境限制已在测试报告中明确。
- 发布版本与被测版本、源码提交和部署配置一致。

### 3.6 暂停与恢复

出现以下情况暂停受影响范围：

- 构建不可访问、认证不可用或核心测试数据无法建立。
- 测试环境混入生产数据或存在凭据泄露风险。
- 基线发生未登记变更。
- 数据库迁移、RLS 或 API Contract 与交付说明不一致。
- S0 缺陷导致继续测试可能扩大数据损坏或泄露。

问题解除并确认版本后，从受影响模块冒烟开始恢复，再执行关联回归。

## 6. 测试数据规则

### 6.1 账户与权限

- 使用合成账户，不使用真实个人邮箱、真实实验内容或生产数据。
- 至少准备用户 A、用户 B、全新空账户 C；A/B 数据形态相似但 ID、空间和内容明显不同。
- 所有 RLS 负向用例必须同时覆盖匿名、A 访问 B、B 访问 A、伪造关联外键和过期会话。
- 特权测试种子仅用于隔离测试环境初始化，不进入浏览器、不写入仓库、不输出凭据值。

### 6.2 时间与时区

- 至少覆盖 `Asia/Shanghai`、`Asia/Kolkata`、`Pacific/Kiritimati`、`Pacific/Honolulu` 和一个有夏令时的 IANA 时区。
- 使用可控制的服务端时钟或测试调度器；不得通过修改生产系统时间制造场景。
- 数据集包含午夜前后、月末、年末、闰日、夏令时跳变和客户端时钟偏差。
- 逾期数据固定包含早 11:59:59/12:00:00、中 17:59:59/18:00:00、晚 23:59:59/次日 00:00:00，以及精确结束时间前后各一条。
- 预期结果从服务端时间事实和 IANA 时区规则计算，不以页面倒计时 tick 作为事实来源。
- 提醒专项记录 `target_end_at`、系统领取时间、站内形成时间和前台显示时间，用于断言 2 分钟/60 秒窗口。

### 6.3 业务数据

- 每类对象覆盖空值、最小合法值、典型值、契约最大值和超过最大值。
- 文本覆盖中文、英文、Unicode、换行、前后空格、超长文本、CSV 特殊字符和潜在注入字符串；仅作为无害测试数据。
- 纯文本数据额外覆盖 Markdown 符号、HTML 标签和脚本样式字符，验证只作为文本保存、转义和展示。
- 方案至少包含两个版本、一个已停用版本和一个被历史执行引用的版本。
- 任务至少包含早/中/晚、进行中、等待中、已完成、已取消和已逾期状态。
- 清单和步骤包含已勾选、未勾选、取消完成、跳过原因和备注。
- 多计时器至少覆盖同实验两个、不同实验两个、同时到期和跨午夜。
- 容量数据集固定为最多 1,000 个注册账户、100 个并发活跃用户；单账户代表性容量为 5,000 个日程、500 个方案、20,000 条步骤或准备项、10,000 条计时和提醒记录。
- 状态数据覆盖所有任务状态优先级、方案草稿/待复核/已确认/已停用、必要/可选步骤和相似方案提示。

### 6.4 离线与并发

- 每个离线操作带唯一事件 ID、对象 revision、客户端时间和同步状态，便于断言只执行一次。
- 并发用例保存操作前 revision、两端请求顺序和最终服务端事实。
- 冲突数据必须区分“同字段冲突”和“无关字段并行修改”，避免把所有并发都误判为冲突。
- 离线时间边界至少覆盖 7:59:59、8:00:00、8:00:01、23:59:59、24:00:00 和 24:00:01。
- 测试结束后清理 IndexedDB、Service Worker 缓存、Push 订阅和测试账户会话，防止用例相互污染。

### 6.5 隐私与保留

- 截图、视频、日志和缺陷附件不得包含令牌、密码、签名下载地址或真实实验私密内容。
- 日志验证只检查是否脱敏，不复制敏感值到测试报告。
- 软删除数据标记删除时间并覆盖保留期内恢复；永久删除使用隔离数据和受控时间推进。
- 导出文件存放在受控临时位置，验证完成后按测试环境规则删除。
- 最近删除数据覆盖未完成日程、未锁定方案、随任务恢复的清单/步骤/计时器，以及明确不得删除的执行记录和被引用方案版本。
- 时间边界覆盖账户删除撤销期第 6 天 23:59:59/第 7 天、最近删除第 29 天 23:59:59/第 30 天及误完成撤销第 30 天内外。
- 保留期数据使用可控数据库时间和隔离种子，覆盖 90 天、365 天、1 年、2 年边界前后；不得修改生产时间或使用生产数据演练。

## 7. 缺陷严重度

| 等级 | 定义 | 示例 |
|---|---|---|
| S0 致命 | 数据泄露、认证绕过、不可恢复数据损坏、生产整体不可用或继续测试会扩大风险 | 跨账户读取/导出；RLS 绕过；历史执行记录被覆盖；生产公开实验数据 |
| S1 严重 | P0 核心闭环或任一 AC 无法完成，且无安全可接受的绕行方案 | 无法登录/归档；离线操作丢失；计时事实错误；Push 失败且无站内提醒；核心支持浏览器不可用 |
| S2 一般 | 非核心能力异常或存在明确、低风险绕行方案 | 个别筛选错误、非关键状态文案不一致、次要浏览器局部问题 |
| S3 轻微 | 不影响任务完成、数据、安全或理解的低影响体验问题 | 轻微间距、非关键文案或视觉偏差 |

缺陷单必须包含：唯一标题、版本/环境、严重度、影响范围、前置数据、最短稳定复现步骤、期望结果、实际结果和必要证据。测试部描述问题和风险，不替开发部指定实现方案。

## 8. 发布阻断规则

任一条件满足即阻断发布：

1. 存在未关闭的 S0 或 S1。
2. 任一 AC-P0-01 至 AC-P0-12 未通过、未执行或被阻塞且无产品部批准的范围变更。
3. 发生跨账户读取、写入、搜索、聚合、导出或缓存泄露。
4. 发生关键记录丢失、重复生效、历史执行版本被覆盖或离线/跨设备静默覆盖。
5. 计时器不以服务端目标结束时间恢复、到期自动完成步骤/实验，或提醒完全丢失且无站内补显。
6. 同一用户同一当地日期生成重复有效汇总，或系统未经确认自动顺延/完成任务。
7. JSON/CSV 导出越权、缺失冻结范围内关键数据、包含永久删除数据/内部日志，或文件可被其他用户访问。
8. 正式支持浏览器或必测桌面/手机宽度不能完成核心闭环。
9. 存在关键文字截断、控件遮挡、主要操作键盘不可达或无可理解标签。
10. Sites 生产环境的认证回调、Supabase 连接、SSR/API、PWA、Service Worker、Push 降级或环境变量失败，且未按已批准条件回退 Vercel。
11. 生产版本与被测提交/配置不一致，或无法证明部署版本来源。
12. 正常 staging 网络下到期任务未在目标时间后 2 分钟内形成站内提醒，或站内提醒形成后前台未在 60 秒内自动显示且刷新后仍不可见。
13. 8 小时离线目标、24 小时待同步保留、旧 revision 拒绝或双值冲突处理任一失败。
14. 核心流程不符合 WCAG 2.2 AA，或键盘/基本屏幕阅读器语义问题阻断核心任务。
15. 账户删除撤销、最近删除恢复、历史不可删除边界或跨账户删除隔离失败。
16. 在冻结代表性容量和正常网络下，普通页面或核心写操作 P95 超过 1 秒，或中端移动设备出现明显不可操作阻塞。
17. 时间冲突未经确认即可保存、未完成准备快照丢失、离线跳过原因可为空、完成阻断条件失效、任务/方案状态错误、误完成无法按期撤销，或 P0 出现方案合并。
18. 逾期边界、纯文本安全展示、软删除导出范围或正式保留期限不符合冻结基线第 9 节。
19. 生产未配置受控邮件服务，或备份/恢复未证明 RPO ≤ 24 小时、RTO ≤ 4 小时。
20. 通知、汇总或审计清理级联破坏实验执行历史、方案版本或计时事实。
21. Sites M0 或 Vercel 回退预案未验证，或回退改变 API、数据模型、RLS、业务规则和验收标准。

S2 仅可在不影响 AC、安全、数据完整性和核心闭环时，由产品部书面接受风险后遗留；S3 可记录进入后续版本。测试部不以口头承诺替代关闭或风险接受记录。
